# Карта документации

- `RULES.md` — конвенции кода и работы, включая поведение агента, и правила текста `README.md`
- `PROTOCOL.md` — протокол сессии, таск-файлы, статус «готово», закрытие вехи, порядок на месте
- `DESCRIPTION.md` — спецификация: цели, стек, ключевые решения
- `architecture/ARCHITECTURE.md` — устройство системы, правила зависимостей, анти-паттерны, § Области; читать перед правкой кода общую часть и файл области
- `architecture/<область>.md` — устройство кода области; читать перед правкой кода общую часть и файл области
- `GLOSSARY.md` — канонические термины: строка на термин
- `ROADMAP.md` — вехи, строка на задачу, открытые вопросы
- `tasks/` — таск-файл на задачу: статус, постановка с очередью шагов, перезаписываемый контекст
- `JOURNAL.md` — журнал работ: новые сверху
- `DECISIONS.md` — реестр решений пользователя: вопрос агента → ответ; новые сверху
- `DONE.md` — архив закрытых вех
- `researches/` — логи разведки по датам: как пришли к решениям; `researches/2026-11-05-recipes.md` — чтение сторонних источников и чистка истории git
