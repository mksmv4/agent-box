Этап 1 — ресерч.

Шаг этапа называет одной фразой, что за дело делает задача, — например, «выгрузка таблицы в CSV», — и ищет, как такое дело обычно делают и где оно ломается: готовые решения и библиотеки, типовые ошибки, советы документации — поиск в интернете, документация инструментов проекта, прошлые ресерчи `docs/researches/` и решения пользователя в `docs/DECISIONS.md` grep-ом по словам темы — и по каждой находке решает, к месту ли она в этой задаче, по `docs/PROTOCOL.md` § Ресерч и проверка постановки. У каждого утверждения — источник: адрес страницы или файл; вывод по выдаче поиска без чтения страницы так и помечен; закрытая ограничением сети контейнера страница, от которой зависит вывод, — блокер по `docs/PROTOCOL.md` § Таск-файлы. Итог — `docs/researches/<дата>-<задача>.md`: практики и решение по каждой, в конце — правки задачи, у каждой «сейчас → после» и зачем, или вывод «по ресерчу нынешний план оптимален» с причиной. Дальше в очереди проверка постановки — чекбокс, правки возьмёт она; иначе правки — блокером по тому же разделу, без правок — чекбокс.

10. Вопросы и итоги сессий скрипта и оркестратора называют шаг его названием в кавычках, без номера, — история файла задачи invite, истории сессий скрипта, беседа шага 5.
11. Итоги на «готово» у сессии скрипта и оркестратора несут предложение о письме-напоминании самим текстом и одно следующее действие — истории сессий скрипта, беседа шага 5.
12. В шагах 4 и 5 сообщение с вопросом или итогом — последний текст хода, окно выбора — только следующим ходом; в вариантах окна нет команд и путей к файлам — истории бесед шагов 4 и 5.

Предложение: прогон — шесть шагов ниже, на компьютере и в чате Claude. Его можно остановить на любом шаге — тогда назови в ответе, на каком.

Сделать руками:

1. компьютер — пересобрать образ
   Вход: терминал в папке agent-box
   Зачем: в образ попадёт образец проекта со всеми починками этой задачи.
   ```
   docker compose build claude
   ```
2. компьютер — завести тестовый проект
   Зачем: проект с задачей-приглашением на праздник, которая ждёт ответа на три вопроса.
   ```
   bash my_local/general-rules/live-run.sh
   ```
   Увидишь «образ собран:» с сегодняшним временем и «тестовый проект готов: /tmp/gr-run».
3. компьютер — беседа без скилла
   Зачем: обычная беседа отвечает о спрошенном, а на «не понимаю» объясняет проще.
   ```
   (cd /tmp/gr-run && claude)
   ```
   На вопрос, доверяешь ли папке, — да. Отправь три сообщения ниже по одному, каждое — после ответа на прошлое. Claude не закрывай.
   ```
   не понимаю, как дальше работать по задаче invite
   ```
   ```
   не понимаю
   ```
   ```
   какой вопрос я тебе задал?
   ```
4. чат Claude — завести задачу
   Вход: сессия Claude из шага 3
   Зачем: заведение задачи переспрашивает, когда твой ответ отменил добавленное Claude.
   ```
   /clear
   ```
   ```
   /box-task памятка новичку: что поставить и куда писать
   ```
   На первый вопрос ответь своим текстом: вариант по вкусу и следом фраза ниже. Дальше отвечай как хочешь, на вопрос о ресерче и проверке — «без них». Шаг кончается, когда Claude напишет, что задача заведена.
   ```
   описание устарело: почта теперь Gmail, чат — Telegram
   ```
5. чат Claude — оркестратор на задаче-приглашении
   Зачем: ответ, отменивший остальные вопросы, ведёт к пересмотру плана — главная проверка прогона.
   ```
   /clear
   ```
   ```
   /box-orchestrate invite
   ```
   Первый вопрос — где и когда праздник: ответь своим текстом, первой строкой ниже. На пересмотр плана — согласие, на новые вопросы — как хочешь, на вопрос о тексте приглашения — своим текстом, второй строкой ниже.
   Страницу задачи в браузере смотреть не нужно. Шаг кончается итогом оркестратора: задача готова. Потом закрой Claude — терминал вернётся в папку agent-box.
   ```
   в этом году офиса нет: все на удалёнке, праздник онлайн
   ```
   ```
   норм, но добавь в конце: «Приходите с хорошим настроением!»
   ```
   ```
   /exit
   ```
6. компьютер — убрать тестовый проект
   Вход: терминал из шага 1, он снова в папке agent-box
   Зачем: копия прогона остаётся для проверки, остальное убирается.
   ```
   bash my_local/general-rules/live-run.sh clean
   ```
   Копия ляжет в новую папку `my_local/general-rules/run-<дата>-<время>/`, путь скрипт напечатает. Тестовый проект, истории его бесед и сеть Docker уберутся.
