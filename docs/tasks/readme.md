# readme

## Постановка

Цель: `README.md` agent-box читается человеком. Читатель — автор обвязки или новый пользователь — по оглавлению находит свой сценарий: поставить обвязку на машину, завести проект, работать в нём, вести задачу движком или оркестратором, обновить обвязку и заведённые проекты, пересобрать образ — и доходит до готовых команд, не читая подробностей устройства. Факты README сходятся с кодом. Подробности, ушедшие из README, живут в своих документах по `docs/README.md`, README ссылается на них. Итог анализа — ресерч `researches/2026-10-14-readme.md`: разбор нынешнего README, сверка с кодом, источники о README, предложение структуры и макет.

Повод — беседа 2026-10-14. На вопрос «как обновить обвязку там, где она была» README одного ответа не дал: части лежат в трёх разделах, порядка для проекта по старой схеме и для рабочей копии git нет. Жалоба пользователя: в README слишком много текста — автор проекта сам не может его прочитать.

Границы: README проектов — карточка `skills/box-init/documents.md` § `README.md` — задача не правит: карточки правятся по прямому разрешению пользователя (`RULES.md` § Конвенции работы); предложение по ней — в хвосты «Контекста».

## Блокер

Почему так вышло. `/box-init`, `/box-task` и `/box-next` набираются в Claude в контейнере — его запуск уже показан во втором шаге быстрого старта. Оркестратор работает только в Claude на компьютере: он сам запускает скрипт, а скрипт — контейнеры. В контейнере скрипта нет, и там оркестратор остановится. Поэтому я выделил запуск отдельно.

Но отдельный блок `claude` лишний: это обычная команда Claude Code, место хватает назвать словами. А `/box-init` и `/box-next` в макете стоят внутри текста, хотя `/box-task` — блоком кода. Это моя непоследовательность: принятые правила текста требуют команду блоком.

Предложение — все команды в Claude записать одинаково, как сейчас `/box-task`:

- `/box-init`, `/box-task`, `/box-next <задача>`, `/box-orchestrate <задача>` — каждая отдельным блоком кода;
- перед блоком — где её набрать: «в сессии Claude в контейнере» или «в Claude на компьютере, запущенном в папке проекта»;
- блок с командой `claude` убрать.

Ок — правлю так файл макета и переписываю README целиком в этом порядке.

Как ответить: допиши в конец файла docs/tasks/readme.md строку, которая начинается с «ответ:», — «ответ: ок» или «ответ:» и свой вариант. Потом запусти в Claude /box-next readme или в терминале agent-loop.sh readme.
