# rakes-architecture

## Постановка

Цель: `AGENTS.md`, который загружает каждая сессия, держит ограничения проекта, а бывшие записи граблей лежат в документах по своей теме; протокол больше не просит сессию искать в конце работы, что бы записать. Архитектура agent-box разделена по областям кода: перед правкой сессия читает общую часть и файл своей области. Повторная сборка документации в проекте кладёт новую задачу под ту же веху.

Повод — беседа 2026-11-05. Раздел граблей вырос с 2,7 тыс. знаков 2026-10-11 до 14,2 тыс. 2026-10-30 и занял 80% `AGENTS.md`; раздел «Жёсткие ограничения», о котором протокол молчит, за то же время остался на трёх записях. Архитектура — 79,5 тыс. знаков при пороге раздела 50 тыс.; предложение раздела лежало в хвостах `docs/tasks/areas-config.md`. Решения — `docs/DECISIONS.md`, 2026-11-05.

## Блокер

Последний шаг задачи — проверка руками на новом образе: заводит ли agent-box свежий проект без правила о граблях и кладёт ли повторная сборка документации новую задачу под ту же веху. Новый образ действует только в новом контейнере, поэтому проверку ведёшь ты. Понадобятся два запуска Claude в тестовой папке.

**Сделать руками** — в терминале, по порядку:

1. В папке agent-box пересобери образ. Сессии Claude в контейнере, открытые раньше, закрой: они работают со старыми командами.

   ```
   docker compose build claude
   ```

2. Создай пустую тестовую папку и запусти в ней Claude:

   ```
   mkdir /tmp/rakeslive && cd /tmp/rakeslive
   box-connect
   ```

   В Claude выполни команду ниже. На список адресов ответь «ок», на вопрос о хранении архива — любой вариант. Когда Claude закончит, выйди из него.

   ```
   /box-init
   ```

3. Посмотри результат первого запуска:

   ```
   grep -ci 'грабл' AGENTS.md docs/PROTOCOL.md
   cat docs/ROADMAP.md
   ```

   Ждём: у обоих файлов счётчик 0. В роадмапе одна веха «Сборка документации» без даты, под ней одна задача.

4. Отметь задачу сборки готовой и запусти Claude снова. Этот шаг делай в тот же день, что и шаг 2: на другой день имя новой задачи будет с новой датой.

   ```
   sed -i '1s/.*/статус: готово/' docs/tasks/docs-*.md
   git commit -qam 'docs task done'
   docker compose -f claude-box.yml run --rm claude
   ```

   В Claude снова выполни команду ниже, ответы те же. Потом выйди.

   ```
   /box-init
   ```

5. Посмотри результат второго запуска:

   ```
   cat docs/ROADMAP.md
   ls docs/tasks
   ```

   Ждём: веха по-прежнему одна, без даты, под ней две задачи. В папке задач два файла, имя второго кончается на `-2`.

6. Убери за собой тестовую папку, историю её сессий и сеть Docker:

   ```
   cd ~
   rm -rf /tmp/rakeslive
   rm -rf ~/.claude-box/.claude/projects/-workspace-rakeslive
   docker network rm rakeslive_default
   ```

Как ответить: допиши в конец файла docs/tasks/rakes-architecture.md строку, которая начинается с «ответ:», и после двоеточия — сам ответ: что совпало с ожидаемым, что нет. Потом запусти в Claude /box-next rakes-architecture или в терминале agent-loop.sh --host rakes-architecture.
