# loop-api

## Постановка
Просьба пользователя, 2026-11-21: «можем сделать флаг для неинтерактивных сессий под апи?»; «мне нужно чтобы скилы тоже умели запускать циклы по апи»; «несколько флагов же можно ставить?»

Решения по теме: кредиты кончились посреди задачи — оркестратор сам продолжает на подписке и сообщает об этом: «2» (2026-11-21); этапы ресерча и проверки постановки — оба: «1» (2026-11-21).

Дописала сессия:
- повод — ежемесячные API-кредиты плана Max (100 $): по документации Anthropic их тратит `claude -p` с ключом организации Console, привязанной к подписке, а интерактивный Claude Code они не покрывают — https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers, https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan; итерация движка — как раз `claude -p`;
- ключ из Console — строка `ANTHROPIC_API_KEY` в `~/.config/agent-loop.env`; `agent-loop.sh --api` отдаёт его только итерациям движка, в контейнере и с `--host`; без флага и в интерактивных сессиях — `box-connect`, ручной запуск контейнера — ключа нет, всё по подписке;
- запуск с `--api` без строки ключа в файле — остановка движка с ошибкой: без ключа итерация молча пошла бы по подписке;
- флаг ставится вместе с прочими и в любом порядке: `--host` или `--no-firewall`, `--quiet`, `--resume`, у оркестратора — слово `telegram`;
- цикл из скиллов запускает сам только `/box-orchestrate`: `/box-orchestrate <задача> --api` передаёт флаг движку на каждом запуске за беседу, как `--host`; `/box-review` и `/box-qa` только называют команду запуска;
- ключ в окружении Claude видят команды агента, `printenv` его покажет; README советует под флаг отдельный workspace Console с лимитом трат и отдельный ключ;
- ресерч ищет точный текст ошибки исчерпанных кредитов — по нему оркестратор узнаёт, что пора на подписку, — и способ спрятать ключ от команд агента;
- последний шаг — живой прогон пользователя после пересборки образа (`docs/RULES.md` § Конвенции работы): расход пробного запуска на странице Cost в Console;
- имя задачи и веха «Сессия хоста над движком».

Цель: `agent-loop.sh --api <задача>` ведёт итерации движка — в контейнере и с `--host` — на API-ключе из `~/.config/agent-loop.env`, и расход идёт с API-кредитов организации Console; без флага, а в интерактивных сессиях всегда, Claude Code работает по подписке и ключа в окружении нет; `/box-orchestrate <задача> --api` передаёт флаг движку на каждом запуске, а на ошибке исчерпанных кредитов или лимита трат Console перезапускает движок без `--api`, сообщает об этом пользователю и до конца беседы запускает движок без флага; `--api` ставится вместе с прочими флагами движка и оркестратора.

Блокер: правки задачи по ресерчу и проверке постановки; итог живого прогона, видный только глазами, — расход на странице Cost в Console.

Этап 1 — ресерч.

Шаг этапа называет одной фразой, что за дело делает задача, — например, «выгрузка таблицы в CSV», — и ищет, как такое дело обычно делают и где оно ломается: готовые решения и библиотеки, типовые ошибки, советы документации — поиск в интернете, документация инструментов проекта, прошлые ресерчи `docs/researches/` и решения пользователя в `docs/DECISIONS.md` grep-ом по словам темы — и по каждой находке решает, к месту ли она в этой задаче, по `docs/PROTOCOL.md` § Ресерч и проверка постановки. У каждого утверждения — источник: адрес страницы или файл; вывод по выдаче поиска без чтения страницы так и помечен; закрытая ограничением сети контейнера страница, от которой зависит вывод, — блокер по `docs/PROTOCOL.md` § Таск-файлы. Итог — `docs/researches/<дата>-<задача>.md`: практики и решение по каждой, в конце — правки задачи, у каждой «сейчас → после» и зачем, или вывод «по ресерчу нынешний план оптимален» с причиной. Дальше в очереди проверка постановки — чекбокс, правки возьмёт она; иначе правки — блокером по тому же разделу, без правок — чекбокс.

Подсказки шагу «Оркестратор и README»:
- строка старта движка с флагом — «итерации на API-ключе из <файл>: расход — с API-кредитов организации Console»; строка повтора в подсказках «дальше:» и в журнале цикла несёт `--api`: после отката оркестратор берёт свою команду запуска без флага, а не подсказку движка прошлого запуска;
- `--api` без строки ключа — код 2 со строкой «--api: в <файл> нет строки ANTHROPIC_API_KEY — …»: оркестратор на коде 2 спрашивает пользователя (шаг 3 скилла);
- README: после включённых кредитов цикл тратит купленные кредиты, если они есть или включено автопополнение, — остановит его лимит трат workspace; ключ видят команды агента и тесты проекта; `--api` в контейнере работает после пересборки образа — образ до флага отдаёт ключ под именем движка, и итерации идут по подписке;
- откат без `--api` идёт путём сбоя API — итерацию с правками без коммита оркестратор перезапускает с резюме её сессии; признак отката — в «Постановке», тексты ошибок кредитов и лимита трат — в `docs/researches/2026-11-21-loop-api.md`.
