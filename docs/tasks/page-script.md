# page-script

## Постановка

Цель: страницу задачи оркестратор ведёт без агента страницы — создание страницы, галочку шага, строку новой итерации, состояние в шапке, блок вопроса и «готово» он делает командой скрипта по файлу страницы и одним вызовом публикации; заголовок, лид и цель новой страницы обычными словами — несколько фраз, которые оркестратор передаёт скрипту, схем на странице нет; вопросы пользователю идут словами протокола — шаг, задача, веха, итерация, — без придуманных замен. Повод — беседа оркестратора пилотного проекта `9cfcdaef-ae66-48dd-902c-fe94c9b2c26c` 2026-10-19: агент страницы запускался 10 раз — 6 на начала итераций, 4 на один вопрос (первый показ и три повтора после переспросов пользователя), каждый стартовал с 56 тыс. токенов контекста и кончал на 90–113 тыс., а сама правка у него — одна команда скрипта по файлу и один вызов публикации; вопрос шёл словами «заход» и «часть работы», потому что скилл запрещает в вопросе «закрыть шаг» и названия шагов, а образец «понятно» в `questions.md` сам пишет «ещё заход». Решение пользователя об агенте на отметки — `DECISIONS.md` 2026-10-18 («чтобы на [чёртовы] галочки не вызывался .. агент»).

Прогон проводит пользователь: в цикле шаг кончается блокером с просьбой о прогоне, в ответ — id беседы оркестратора. Проверка шага: текстовые шаги — сверка в «Контексте» по описанию шага; прогон — числа по истории беседы Claude на хосте `~/.claude/projects/<папка проекта>/<id беседы>.jsonl`: занятость контекста на каждом вызове инструмента — `jq -r 'select(.type=="assistant") | .message as $m | ($m.usage | (.input_tokens//0)+(.cache_creation_input_tokens//0)+(.cache_read_input_tokens//0)+(.output_tokens//0)) as $t | ($m.content[]? | select(.type=="tool_use") | "\($t)\t\(.name)")' <файл>`.

Блокер: скрипт не находит место правки без чтения страницы — метки в разметке не держатся; публикация оркестратором отклоняется иначе, чем отказ «не видел живую версию»; живой прогон — пользователь. Движок по задаче — с `--host` (`AGENTS.md` § Грабли): у итерации инструмента `Artifact` нет, публикация проверяется только живым прогоном.
