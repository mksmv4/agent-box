# agent-loop

## Постановка

Цель: пользователь запускает на хосте одну команду с именем задачи — и задача проекта идёт итерациями `/box-next` без ручного запуска каждой сессии, на хосте и в контейнере; остановки, таймер и уведомления в Telegram — по `ARCHITECTURE.md` § Движок автоцикла. Контейнерная ступень защищена: deny-правила образца закрывают неприкасаемое, egress-firewall пропускает только разрешённые адреса, правка агентом `compose.yml` своего проекта закрыта. Итог `/box-task` называет команду запуска движка. Потолок ходов, порог «без прогресса» и порог таймера выбраны пользователем по обкатке. Открытые вопросы `ROADMAP.md` § Движок автоцикла закрыты.

## Контекст

Шаг «Список адресов проекта в `/box-init`» сделан в файлах и ждёт живой проверки — секция «Блокер». Ответ «ок» — чекбокс шага, запись в `DECISIONS.md`, журнал; дальше — шаг «Итог `/box-task`…», начать с `skills/box-task/SKILL.md`. Другой ответ — правка по нему в `skills/box-init/SKILL.md` § 3 «Адреса проекта» и снова живая проверка.

Сделано: в `/box-init` — шаг 3 «Адреса проекта» при любом заходе (сбор, список с причинами на правку, пометки «уже открыт» и «не найден», строка `CLAUDE_BOX_ALLOW` в compose-файл или в итог), прежние шаги 3–6 стали 4–7; правило блокера на закрытом адресе — `template/docs/PROTOCOL.md` § Таск-файлы с копией в `docs/PROTOCOL.md`; README и `ARCHITECTURE.md` (§ Скиллы контейнера, § Образ и скрипт запуска — с пробой текстов ошибок закрытого адреса).

Хвосты:

- Правило блокера на закрытом адресе вживую не проверено: сессия за ограничением сети, упёршаяся в адрес, — при обкатке. До проектов оно доезжает через `/box-update` или повторный `/box-init`.
- Доступность чужих сайтов Cloudflare и Fastly через адреса npm и PyPI не проверена: пробу отклонил классификатор режима auto прошлой сессии.
- Наблюдения живой проверки правил запрета: отказ по `.env` агент дал сначала сам — по глобальному правилу о секретах из `~/.claude/CLAUDE.md` хоста, который едет в контейнер; правило запрета отклонило его следующую команду — вывод имён переменных, и агент назвал это отказом пользователя. Правило `Edit` на compose-файл в проверке не сработало ни разу: агент увидел подключение только на чтение и инструментом правки не пробовал. На машине без глобального правила барьер по `.env` — только правило запрета.
- Пути, которых защита не закрывает: `.git/commondir` переадресует настройки git — ручной `git status` пользователя на хосте выполнит подложенную команду; флаги движка проверены только на fsmonitor и хуках, другие команды из переадресованных настроек git не проверялись. `.claude/settings.local.json` с хуками, записанный скриптом агента, сработает в сессии Claude Code на хосте. Скрипт агента обходит правила запрета. Варианты `.env` вне списка имён (`.env.backup` и подобные) открыты.
- Пилотный проект получит правила, подключения только на чтение, права ограничения сети, снятие `env_file` и список адресов повторным `/box-init` в новом контейнере — решает пользователь.
- `--max-turns 200` и порог таймера «до замера — час» (`alert=3600` в скрипте) выбраны агентом без согласия пользователя — `DECISIONS.md` 2026-09-30 «правка реестра по сверке с переписками»; числа решает пользователь.
- Ctrl+C во время итерации по настоящей сессии не проверялся ни на хосте, ни в контейнере; в контейнере Compose отдаёт SIGINT сессии и сразу выходит с 130 (проба на `sh`).
- Предложение нового шага: проверка токена при старте движка (метод `getMe`) — неверный токен виден сразу при запуске, пока пользователь у терминала, а не на первой остановке; ответ Telegram «Not Found» переводится в «неверный токен».

Среда на 2026-10-04: хост — `docker` с Compose 5.6.0, `git`, `jq`, `python3`; образ `maksim44/claude-box` собран до правки `/box-init` — проверка начинается с пересборки; тестового проекта `~/box-test` нет; сеть `agent-box_default` — сервиса этого репозитория.

## Блокер

`/box-init` теперь собирает адреса интернета, которые нужны проекту, — откуда качаются зависимости, внешние сервисы из кода и примера `.env`, MCP-серверы проекта, сайты документации, — показывает их списком с причинами на правку и по ответу вписывает строку в compose-файл: в автоцикле эти адреса открыты. Адрес, который не находится в интернете, он помечает и в строку не берёт: на таком адресе автоцикл не стартует. Ещё новое правило для сессий проекта: сессия, упёршаяся в закрытый адрес, останавливается блокером с готовой строкой для compose-файла. Нужна проверка на пересобранном образе.

Сделать руками:

1. В папке клона agent-box — пересборка образа:
   `docker compose build claude`
2. Тестовый проект: зависимости с отдельного сервера пакетов, внешний сервис и несуществующий адрес в примере `.env`, MCP-сервер, база в compose-файле:
   `mkdir ~/box-test && cd ~/box-test && git init -q && printf '{"name":"box-test","dependencies":{"express":"^4.19.0"}}\n' >package.json && printf -- '--extra-index-url https://download.pytorch.org/whl/cpu\ndjango==5.1\ntorch\n' >requirements.txt && printf 'DATABASE_URL=postgres://app:app@db:5432/app\nSTRIPE_API_BASE=https://api.stripe.com\nLEGACY_API=https://legacy.box-test.invalid\n' >.env.example && printf '{"mcpServers":{"sentry":{"type":"http","url":"https://mcp.sentry.dev/mcp"}}}\n' >.mcp.json && printf 'services:\n  db:\n    image: postgres:16\n' >compose.yaml && git add -A && git commit -qm init`
3. В `~/box-test` — Claude в контейнере, затем в сессии `/box-init`:
   `docker run --rm -it -v "$PWD":/workspace/box-test -w /workspace/box-test -v "$HOME"/.claude-box:/home/node -v "$HOME":/root/host-home:ro maksim44/claude-box`
   Вопрос о MCP-сервере из `.mcp.json` при старте — любой ответ. В списке адресов убери один на свой выбор; вопрос об архиве — любой ответ. После итога — выход из сессии.
4. Ограничение сети принимает строку адресов:
   `docker compose run --rm -T --entrypoint claude-box-firewall claude --version </dev/null`

Ожидание в п. 3: список с причиной у каждого адреса — сервер пакетов PyTorch из `requirements.txt`, Stripe из `.env.example`, Sentry из `.mcp.json`, сайты документации Django и Express; `legacy.box-test.invalid` — с пометкой «не найден»; базы `db`, npm и PyPI в списке нет. После ответа в `compose.yaml` у сервиса `claude` строка `CLAUDE_BOX_ALLOW` — список без убранного адреса и без `legacy.box-test.invalid`; итог называет эти адреса. Проверка строки: `grep -n CLAUDE_BOX_ALLOW ~/box-test/compose.yaml`. Ожидание в п. 4: строка «claude-box-firewall: сеть ограничена: …, своих адресов проекта N …» с N больше нуля, затем версия Claude Code. Пошло иначе — напиши, на каком пункте и что видно.

Уборка после проверки: `cd ~ && docker network rm box-test_default; rm -rf ~/box-test ~/.claude-box/.claude/projects/-workspace-box-test`

«Ок» — список пришёл с причинами, строка легла в compose-файл, ограничение сети её приняло.

Как ответить: допиши в конец файла docs/tasks/agent-loop.md строку, которая начинается с «ответ:», — «ответ: ок» или «ответ:» и свой вариант. Потом запусти в Claude /box-next agent-loop или в терминале agent-loop.sh --host agent-loop.
