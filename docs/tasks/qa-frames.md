# qa-frames

## Постановка

Цель: страница задачи оркестратора публикуется при любом числе кадров QA. Кадры сценария склеены в вертикальную ленту: нажатие на обложку открывает ленту, её листают прокруткой, кнопки «+» и «−» увеличивают только ленту, и её можно двигать вбок. Файлы, которых на странице больше нет, публикация убирает. Сессия QA снимает в окне браузера 1440×900.

Повод — пилотный проект 2026-11-06: 797 кадров при пределе 511 файлов на версию страницы, публикации страницы падали с вечера 2026-11-05 ошибкой `manifest exceeds 512 entries`. Кадры там 3440×1301 — окно браузера во весь широкий монитор, сайт занимает треть ширины. Замер на 30 кадрах: PNG — 229 КБ, WebP с качеством 80 — 68 КБ, текст не отличить, JPEG с качеством 85 — 218 КБ. Решения — `docs/DECISIONS.md`, 2026-11-06; лента прокруткой заменяет листание кадров по одному из решения 2026-10-30.

Очередь:

- [ ] Склейка и уборка в скрипте страницы. Кадры сценария — вертикальная лента из кусков WebP: кадры друг под другом, кусок — до 16 000 пикселей в высоту (предел WebP — 16 383), качество 80; обложка сценария — последний кадр отдельным файлом WebP. Снимки в `my_local/qa/<задача>/` остаются PNG, лента собирается из них одним сжатием. Склейка — библиотекой Pillow; Pillow нет — код 2 и строка с командой установки. Уборка: файлы, отмеченные отправленными и больше не показанные страницей, уходят в JSON `files` ответа скрипта со значением `null`, команда `sent` после удачной публикации снимает их с отметок; в одном ответе — не больше 255 записей, остаток — со следующим событием. Правится `page.py`, `pages.md`, шаг публикации в `SKILL.md` оркестратора, `docs/architecture/orchestrator.md` (скрипт больше не только на стандартной библиотеке), требования в `README.md` — Pillow для оркестратора. Читает: `template/.claude/skills/box-orchestrate/page.py`, `pages.md`, `SKILL.md`, `docs/architecture/orchestrator.md`, `README.md` — 109 тыс. знаков. Проверка: на копии снимков пилотного проекта в тестовой папке скрипт кладёт рядом со страницей ленты и обложки, файлов не больше 150 на 797 кадров; ответ скрипта на странице с отправленными одиночными кадрами несёт их со значением `null`.
- [ ] Окно просмотра ленты. Нажатие на обложку открывает ленту сценария поверх страницы: куски вплотную друг под другом на ширину окна, листание прокруткой, кнопки «+» и «−» меняют ширину ленты, при увеличении лента двигается вбок; закрытие — крестиком и Esc. Листание по одному кадру и счётчик «кадр N из M» уходят. Правится каркас `examples/running.html`, пример `examples/question.html` собирается заново, описание просмотра — в `pages.md`, разметка обложки — в `page.py`. Читает: `examples/running.html`, `examples/question.html`, `pages.md`, `page.py` — 88 тыс. знаков. Проверка: тестовая страница из первого шага открывается в браузере без сети, лента прокручивается, кнопки меняют размер, Esc закрывает.
- [ ] Окно браузера в QA: шаг прогона в `template/.claude/skills/box-qa/SKILL.md` перед первым действием ставит окно браузера 1440×900. Читает: этот файл — 7 тыс. знаков. Проверка: строка в шаге прогона стоит до первого действия.
- [ ] Живая проверка — ведёт пользователь: свежие скиллы в пилотном проекте, страница задачи QA пилотного проекта пересоздаётся по прежнему адресу и публикуется. С компьютера и телефона: ленты открываются, прокручиваются, кнопки «+» и «−» увеличивают ленту, текст читается при увеличении; одиночных кадров на странице нет. Кусок ленты из старых кадров 3440×1301 на телефоне не открывается — предложение резать куски по площади.

Проверка шага: записана у каждого шага.

Блокер: живая проверка; расхождение этой постановки с документами или возможностями инструмента.

## Контекст

Следующий шаг — склейка и уборка: `template/.claude/skills/box-orchestrate/page.py`, кадры собирает `render_browser`, копии и JSON публикации — конец `main`.

Хвосты:
- Окно просмотра лежит в каркасе вне меток, а каркас скрипт берёт из примера только командой `new`: страница пилотного проекта получит новое окно только пересозданием.
- Считается ли удаление файла `null` в предел 255 файлов на публикацию — не проверено; первая публикация пилотного проекта после правки убирает около 500 кадров.
- Пределы показа большой картинки на телефоне не проверены: кусок из 12 кадров 3440×1301 — около 54 мегапикселей, из 17 кадров 1440×900 — около 22.
