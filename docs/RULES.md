# Правила

## Конвенции кода

- Комментарии в коде — на русском, как документы (`DESCRIPTION.md` § Стек), в назывной форме: что делает код и почему так. Пример — `# перенос пути из домашней папки хоста: есть на хосте — свежая копия, нет — копия прошлого запуска убирается` в `container/entrypoint.sh`.
- Файл кода открывается комментарием о назначении и способе вызова: так начинаются `container/Dockerfile` со строкой сборки, `container/entrypoint.sh` и `compose.yml` со строкой запуска.
- Скилл обвязки: имя с префиксом `box-` — так оно не пересекается со скиллами проекта; вызов только командой — `disable-model-invocation: true`, аргумент — `argument-hint`; `description` — что делает скилл и строка вызова; тело — нумерованные шаги.
- Markdown: абзац — одна строка; ссылка на раздел — `` `файл` § Раздел ``; даты — ISO.

## README

Правила текста `README.md` agent-box; README проектов задаёт карточка `skills/box-init/documents.md` § `README.md`. Основания правил — `researches/2026-10-14-readme.md` § Итог и макет.

- Порядок README: что делает проект, быстрый старт, важные настройки, оглавление остального, остальное. Оглавление — строка на раздел: ссылка с текстом заголовка слово в слово и подсказка, когда раздел нужен.
- Раздел после важных настроек — одно дело читателя, заголовок — дело глаголом в начальной форме: «Обновить agent-box и проекты». Разделы «Быстрый старт», «Важные настройки» и «Остальное» названы по своему назначению.
- Требования — списком до первого шага. Шаг — где, что сделать, команда блоком кода, что увидишь после; команда в Claude — тоже отдельным блоком. Где — словами перед блоком, одно из четырёх мест: терминал в папке agent-box, терминал в папке проекта, сессия Claude в контейнере, Claude на компьютере, запущенный в папке проекта. Заполнитель вида `<задача>` поясняется под командой.
- Развилка — условием в начале: «`claude-box.yml` нет — …». Условия стоят в порядке проверки. У дела один способ; второй — только с условием выбора.
- Одна мысль — одно предложение, до 20 слов; абзац — одна тема, до 400 символов. Связки — словами: «потому что», «например»; цепочка «X — Y: Z — W» делится на предложения.
- В README — действия человека и их результат. Справка и устройство — флаги, переменные, перечни правил, механизм — живут в `docs/`; в README от них — фраза причины и ссылка.
- Ссылка на документ — markdown с относительным путём, раздел — после неё: `[docs/architecture/container.md](docs/architecture/container.md) § Ступени изоляции`.
- Продукт называется agent-box. Слова обвязки заменяются обычными: блокер — вопрос, итерация — сессия, движок — скрипт, таск-файл — файл задачи. Имена из файлов — «Блокер», `/box-next` — и слово «оркестратор» остаются как есть, у первого упоминания в разделе — пояснение парой слов: оркестратора читатель ищет по имени.
- Обращение — на «ты», повелительным наклонением: «запусти», «допиши» — как в блокерах.

## Конвенции работы

- Репозиторий публичный. В файлах под git и сообщениях коммитов проект обкатки — «пилотный проект», пути домашней папки — через `~`; названия личных проектов, пути этой машины и детали её настройки живут в `my_local/`, вне git.
- Сообщение коммита — одна строка на английском по Conventional Commits: `type(scope): summary`, scope — часть продукта: `template`, `container`, `skills`, `box-init`.
- Команды, пути и тексты на копирование — в тексте сообщения, по `PROTOCOL.md` § Сообщения пользователю: 2026-10-01 попытка скопировать текст из окна вопроса выбрала вариант «.env в клоне agent-box». Выбор, сделанный так, решением не считается.
- Текст, который блокер просит прочитать на проверку, — макет, черновик, список, — лежит отдельным файлом только с ним, блокер называет файл и его длину в строках. Раздел в конце большого документа пользователь читать не стал: ресерч задачи readme на 509 строк с макетом в конце он отклонил, не начав читать (2026-10-15).
- Подагенты и параллельные запуски агентов — только когда их запуск предусмотрен скиллом или с явного согласия пользователя в текущей беседе.
- Карточки документов `skills/box-init/documents.md` правятся только по прямому разрешению пользователя: дифф — пользователю, запись — после ответа.
- Работа в беседе, часть которой ждёт ответа пользователя — разрешения на правку, согласия, — коммитится после ответа, вся разом, и запись журнала идёт за ней: коммит до ответа выдаёт незаконченное за готовое. Скилл `/box-qa` закоммичен с записью журнала, пока его карточка ждала разрешения, и оба коммита откатывались (2026-10-21).
- Отказ пользователя от предложения окончателен: отказы записаны в `docs/DECISIONS.md`, перед предложением по схеме обвязки — grep по нему; отвергнутое повторно не предлагается.
- Правило из ответа пользователя записывается в границах его слов. Ответ «если тебе доверить миграции ты [наделаешь] бесконечное количество таблиц» запрещал агенту миграции, а скилл оркестратора получил запрет всякой записи в локальную базу; лишний запрет пользователь снял 2026-10-21. Найденный перегиб снимается целиком, без промежуточных границ взамен.
- Скилл оркестратора здесь — ссылка на образец, и его правка ложится во все проекты: срыв, увиденный в прогоне на задаче agent-box, про любой проект правится в образце, про сам agent-box — в `docs/RULES.md`.
- Правка скилла или образа проверяется вживую: пересборка образа (`README.md` § Пересобрать образ после правки agent-box), новый контейнер (`AGENTS.md` § Жёсткие ограничения), прогон на пилотном проекте или тестовой папке. Прогон ведёт пользователь — новой сессией в новом контейнере.
