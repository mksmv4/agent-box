# Ресерч 2026-10-10 — оркестратор над движком: Telegram или Remote Control

Вопрос беседы: как сессии Claude Code на хосте, которая ведёт движок проекта («оркестратор»), слать пользователю вопросы и получать ответы с телефона так, чтобы при нескольких оркестраторах разных проектов каждый получал только ответы своего проекта. Итог — Remote Control (`DECISIONS.md` 2026-10-10 — канал оркестратора к пользователю).

## Чтение из Telegram — отвергнуто пользователем

- Входящие бота Telegram отдаёт одному читателю `getUpdates`: второй одновременный читатель получает 409 Conflict. Официальный Telegram-плагин каналов Claude Code при старте завершает прежний процесс-читатель из той же папки состояния — исходник `external_plugins/telegram/server.ts`, комментарий «Telegram allows exactly one getUpdates consumer per token».
- Разделение проектов при чтении — бот на проект или один бот с постоянным процессом-маршрутизатором.
- Отправка (`sendMessage`) ограничения одного читателя не имеет: общий бот движка годится для уведомлений любых проектов.
- Каналы Claude Code — research preview: плагин доставляет сообщения в открытую сессию, даёт инструмент ответа в чат и пересылает запросы разрешений кнопками. Включаются только флагом запуска `claude --channels plugin:telegram@claude-plugins-official`; плагин работает на Bun; несколько ботов на машине — отдельная папка состояния каждому через `TELEGRAM_STATE_DIR`.

Источники: https://code.claude.com/docs/en/channels, https://github.com/anthropics/claude-plugins-official/tree/main/external_plugins/telegram

## Remote Control — выбран

- Каждый интерактивный процесс `claude` с Remote Control — отдельная сессия в приложении Claude и на claude.ai/code; название — аргументом `claude --remote-control "<имя>"` или `/remote-control <имя>`. Проекты разделены сессиями.
- Включение: флаг `--remote-control` (`--rc`), команда `/remote-control` (`/rc`) в открытой сессии или `/config` → «Enable Remote Control for all sessions» (ключ `remoteControlAtStartup`). `/rc` в открытой сессии показывает ссылку, QR-код и отключение.
- Требования: подписка Pro, Max, Team или Enterprise и вход через claude.ai. С API-ключом, `ANTHROPIC_BASE_URL` на чужой хост или `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` Remote Control недоступен.
- Пуши в приложение Claude — два переключателя `/config`: «Push when actions required» — запросы разрешений и вопросы `AskUserQuestion`; «Push when Claude decides» — по решению модели, обычно конец долгой работы или нужда в решении. Пуши пропускаются, пока пользователь печатает в подключённом терминале или терминал в фокусе. Запросы разрешений и вопросы висят открытыми до ответа.
- Режим сервера — `claude remote-control` в папке проекта: с телефона открываются новые сессии на машине в этой папке, до 32 по умолчанию; `--spawn worktree` — каждой новой сессии свой git worktree. Флаги перед `remote-control` в сессии сервера не переходят, режим разрешений — `--permission-mode`. Сессии остановленного Ctrl+C сервера возвращает `claude remote-control` в той же папке — около четырёх часов.
- Сеть компьютера пропала: сервер сдаётся примерно через 10 минут и завершается, интерактивная сессия переподключается сама. Пропажа сети телефона в доке не описана; сессия всё время работает на компьютере.
- Только в локальном терминале работают `/plugin` и `/resume`.

Источник: https://code.claude.com/docs/en/remote-control

## Инструменты сессии оркестратора — описания инструментов CLI 2.1.296

- Явный пуш — инструмент `PushNotification`: уведомление в терминале и, при подключённом Remote Control, пуш на телефон; пропускается, когда пользователь у терминала. Статус `proactive` по описанию соответствует переключателю «Push when Claude decides»; вживую не проверено.
- Пробуждение по событию: фоновая команда Bash (`run_in_background`) будит сессию своим завершением; инструмент `Monitor` превращает каждую строку вывода фоновой команды в событие сессии, наблюдение живёт до 30 минут и перевзводится.
- Страницы — инструмент `Artifact`: приватная страница на claude.ai по ссылке, обновление — повторной публикацией того же файла; база страницы и прочие возможности — по аккаунту, их список даёт скилл `artifact-capabilities`.
