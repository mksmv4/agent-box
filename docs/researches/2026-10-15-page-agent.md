# Ресерч 2026-10-15 — агент страницы задачи

Вопрос задачи orchestrator-context, шаг «Проба подагента со страницей»: публикует ли подагент сессии хоста существующую страницу задачи и во что публикация обходится ему и вызывающей сессии. Цель задачи и замеры до неё — `tasks/orchestrator-context.md` § Постановка и § Контекст.

## Условия пробы

- Интерактивная сессия Claude Code 2.1.300 на хосте в режиме auto; модель сессии и подагентов — `claude-opus-5-5`, подагент наследует модель сессии.
- Подагент общего назначения (`general-purpose`), фоновый запуск. Задание: опубликовать файл страницы areas-config `my_local/pages/areas-config.html` — 63 895 байт, 48 222 знака — как есть, новой версией по её адресу из `my_local/pages/links.md`; на отказ — указание отказа и повтор, до трёх вызовов публикации; ответ — по вопросам пробы. Второй, новый подагент получил то же задание через 15 с после конца первого.
- Замеры — по истории сессии `~/.claude/projects/<папка проекта>/<id сессии>.jsonl` командой из «Проверки шага» таск-файла и по историям подагентов (§ Расход подагента).

## Запуск подагента в режиме auto

Первый запуск, с разрешением только в «Постановке» таск-файла, классификатор режима auto отклонил: `[Auto-Mode Bypass]`. После слов пользователя в беседе «запускай два подагента» прошли оба запуска (`AGENTS.md` § Грабли). Запуск агента страницы из скилла оркестратора без согласия в беседе проверяет шаг «Проверка агента страницы вживую».

## Инструмент `Artifact` у подагента

У обоих подагентов `Artifact` — отложенный инструмент: в списке имя без схемы, загрузка — `ToolSearch` запросом `select:Artifact`, плюс 13,4 тыс. токенов контекста подагента. Подагент общего назначения публикует: страница прежняя, адрес прежний. Перед публикацией оба прочитали файл страницы целиком: по словам обоих, описание инструмента велит читать перед публикацией файл, написанный не ими; в бинаре CLI эта фраза не найдена. Чтение — плюс 22,4 тыс.

## Отказ «не видел живую версию»

- Первый подагент: один вызов `publish` с `file_path` и `url`, без чтения живой версии, — публикация прошла, версия 33 (`1792074820-0943`). Ответ инструмента — 1,7 тыс. знаков: адрес, версия, справка о наблюдении за страницей — после конца подагента комментарии страницы, адресованные Claude, приходят вызвавшей сессии.
- Второй подагент, вызов 1: отказ «You hadn't viewed the live version of this artifact, so the publish was refused.» с указанием слить свои правки с живой версией и не отправлять прежнее содержимое без изменений; в отказе — живая страница целиком, сырой HTML в обёртке публикации, 49 206 знаков, плюс 21,7 тыс. токенов контекста подагента.
- Вызов 2, после сверки живой версии с файлом командой Bash — совпали: отказ в 532 знака «Publish refused — nothing was merged or published: this is the identical content already refused against the newer version…»; там же — содержимое, уже сверенное с живой версией, проходит повторной отправкой без изменений.
- Вызов 3 — успех с той же версией 33 и тем же id: одинаковое содержимое новой версии не заводит.

Живую версию 33 второму подагенту оставил первый, той же сессией, за 30 с до его вызова; версию 32 первому — сессия оркестратора около двух часов раньше. Почему первый отказа не получил, не выяснено. Тексты отказа лежат в бинаре CLI 2.1.300 константами `STALE_GUARD_REJECTION_PREFIX` и соседними, публикация несёт предусловие версии `baseVersion`; решает отказ CLI или сервер — не выяснено. Сессии оркестратора до задачи получали этот отказ на первой публикации существующей страницы (таск-файл, § Постановка и § Контекст): отказ на первой публикации подагента бывает и не бывает, и агент страницы проходит оба исхода.

## Расход подагента

| | первый | второй |
|---|---|---|
| вызовов инструментов, с ответом | 4 | 7 |
| время от запуска до ответа | 22,1 с | 61,4 с |
| контекст на последнем запросе к модели | 68,7 тыс. | 91,3 тыс. |
| запись в кэш за подагента | 68,7 тыс. | 46,0 тыс. |
| чтение из кэша за подагента | 144,9 тыс. | 460,9 тыс. |

Контекст подагента до первого действия — 31,9 тыс.: системный текст, описания инструментов, глобальный `CLAUDE.md` и хаб репозитория. Дальше — схема `Artifact` 13,4 тыс., файл страницы 22,4 тыс., отказ с живой страницей 21,7 тыс., остальное — около 1 тыс. Запись в кэш у второго меньше: начало контекста и схему `Artifact` он взял из кэша первого — на первых двух запросах запись 0. Ответы модели — сотни токенов за подагента.

Где числа видны:

- уведомление о конце подагента в контексте вызывающей сессии — `subagent_tokens` (69 369 и 92 565, около контекста последнего запроса), `tool_uses`, `duration_ms`;
- история подагента `~/.claude/projects/<папка проекта>/<id сессии>/subagents/agent-<id>.jsonl` — `usage` каждого запроса, команда «Проверки шага» работает и на ней; рядом `agent-<id>.meta.json` — тип агента и описание запуска;
- путь `output_file` из ответа запуска ведёт в `/tmp/claude-<uid>/…/tasks/` под id сессии процесса: после `/clear` он отличается от id сессии в истории.

## Рост контекста вызывающей сессии

На вызов подагента — около 2 тыс. токенов: задание подагенту — 1,5 тыс. знаков, около 0,6 тыс. токенов; ответ запуска — 1,1 тыс. знаков; отчёт подагента — 2,7 тыс. и 4,0 тыс. знаков; уведомление о конце — около 1 тыс. знаков. Запись в кэш вызывающей сессии на запросах после ответа запуска и после отчёта — 965 и 972 токена у первого, 1342 и 1501 у второго, вместе с короткими репликами сессии. Короче отчёт — меньше рост: ответ агента страницы одной строкой даёт меньше 2 тыс.

Отчёт второго подагента, где дословно цитировались тексты отказа, оболочка Claude Code пометила как похожий на инструкции (`artifact-lead-forgery`) и обезвредила в нём служебные скобки. Ответ агента страницы без цитат из ответов инструмента этой пометки не получает.

Для сравнения — та же публикация в самой сессии оркестратора: схема `Artifact` 13,4 тыс., файл страницы 22,4 тыс., отказ с живой страницей 21,7 тыс. — до 57 тыс. контекста.

## Итог для шага «Агент страницы»

- Подагент общего назначения публикует страницу сам: запасной вариант «агент готовит файл, публикует оркестратор» не нужен.
- Оркестратору публикация через подагента стоит около 2 тыс. токенов против до 57 тыс. своей публикацией.
- Агенту страницы — 69–92 тыс. контекста, 22–61 с, из них 13 тыс. — схема `Artifact`, 22 тыс. — файл страницы, 22 тыс. — отказ с живой страницей. Отказ агент проходит слиянием с живой версией и повторной публикацией; совпало содержимое — повторной отправкой без изменений.
