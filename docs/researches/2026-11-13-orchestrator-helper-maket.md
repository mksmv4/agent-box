# Макет правок: оркестратор-помощник

Задача `orchestrator-helper`. Что меняется в протоколе проектов и в скилле оркестратора: место, текст сейчас, текст после. Основания — `2026-11-13-orchestrator-helper.md`.

## Что увидишь ты

Сейчас: одно сообщение на семь пунктов в трёх местах, ветки «если ответ 403» и «если другое», список «что прислать», уборка, затем окно «сделано ли». Пункт «на сервере» — без команды входа.

После — сначала одно сообщение:

Сессии нужно 7 шагов в трёх местах.

```
┌─ компьютер ─┐   ssh    ┌─ сервер ──────┐
│ 1 перенос   │ ───────► │ 2 пересборка  │
└─────────────┘          │ 3 бэкап       │
┌─ браузер ───┐          │ 5 бэкап       │
│ 4 создать   │          │ 7 откат       │
│ 6 изменить  │          └───────────────┘
└─────────────┘
```

Шаг 1 из 7 — на компьютере, в терминале в папке проекта:

```
git archive HEAD <папка сервиса> \
  | ssh <сервер> tar -x -C <папка>
```

Пришли, что вывела команда.

Следующее сообщение — после твоего вывода: «Шаг 2 из 7 — на сервере. Войди и перейди в папку проекта: `ssh <сервер>`, `cd <папка>`. Там: … Пришли вывод». Сорвался шаг — одна строка, что не так, и шаг починки. Окно «сделано ли» — одно, после шага 7.

## Протокол, § Сообщения пользователю

Сейчас:

> - просьба сделать что-то руками — отдельным пунктом: что сделать, готовые команды, что написать в ответ; просьба, после которой остаются тестовые папки, сети Docker или истории сессий, кончается готовыми командами уборки;

После:

> - просьба сделать что-то руками — отдельным пунктом, нумерованными шагами. Шаг — одно место и одно дело: где — компьютер, сервер, страница сервиса в браузере, чат Claude; вход туда, когда место сменилось, — команда (`ssh <сервер>`, `cd <папка>`) или адрес страницы; готовые команды; что прислать — вывод или строка, по которой виден итог. Шаг — до пяти строк, не считая команд. Шаг кончается «пришли вывод»: сбой разбирают по присланному, поэтому ветки «если пошло не так» в шаги не идут. Просьба, после которой остаются тестовые папки, сети Docker или истории сессий, кончается шагом уборки с готовыми командами;
> - шаги в двух местах и больше — над шагами схема мест: место — рамкой с номерами своих шагов, переход — стрелкой с командой входа. Схема — блоком кода шириной до 60 знаков, рамки и стрелки — символами: терминал картинок не показывает.

## Скилл оркестратора

**Шаг 4, вторая группа.** Сейчас: «просьба сделать руками — миграция локальной базы, правка compose-файла или настроек Claude Code, вход в сервис». После: «просьба сделать руками за границей шага 8 — миграция локальной базы, правка compose-файла или настроек Claude Code, вход в сервис, рабочий сервер без разрешения на ssh».

**Шаг 4, деление просьбы.** Сейчас: «Просьба сделать руками делится по пунктам: … Пункт первой группы — агенту проверок, пункт второй группы — пользователю, в порядке просьбы: …». После:

> Просьба сделать руками делится на шаги по `docs/PROTOCOL.md` § Сообщения пользователю — одно место, одно дело, — даже когда сессия написала её одним куском. Сессия в контейнере пишет просьбой и то, до чего сама не дотягивается, — запрос к локальной базе, запись её данных, осмотр контейнера, значение из консоли площадки в файл вне git. Шаг-проверка — агенту проверок. Шаг-действие в границах шага 8 оркестратор делает сам, итог — строкой в чат. Остальные шаги — пользователю, по одному, в порядке просьбы: проверка перед действием, например счёт «до», — до шага пользователя, проверка после — по присланному выводу.
>
> Шаг пользователю — отдельным сообщением: «Шаг N из M — <место>», вход туда, когда место сменилось, команды, что прислать. Команды этого компьютера — строками `! <команда>`: вывод ложится в беседу. Перед первым шагом — строка, сколько шагов и где, при двух местах и больше — схема мест. Следующий шаг — после проверки присланного: итог сошёлся — следующий шаг; не сошёлся — одна строка, что не так, и шаг починки.

**Шаг 4, итог сделанного руками.** Сейчас: «Окно у такой просьбы — только о деле: сделано ли; …». После: «Окно у такой просьбы — одно, после последнего шага, только о деле: сделано ли; …» — дальше без изменений.

**Шаг 4, сообщение перед окном.** Сейчас: «просьба сделать руками с готовыми командами — строками `! <команда>` для этой беседы, по одной: …». После: «просьба сделать руками — строкой, сколько шагов и где, схемой мест и первым шагом; окно ждёт последнего шага, пуш — как у вопроса».

**Шаг 8, новый первый пункт:**

> - оркестратор — помощник пользователя: на вопрос отвечает, поручение выполняет сам в границах ниже, пользователю отдаёт то, чего сделать не может, — по шагу. Просьба сессии, пересланная целиком, и ответ о намерении вместо дела — срыв;

**Шаг 8, новый пункт — что оркестратор делает сам** (вопрос 2 блокера):

> - сам оркестратор делает на этом компьютере то, что читает или меняет только контейнеры и образы проекта и файлы вне git: журнал контейнера, команды проверки, остановка и удаление контейнера проекта, поднятого по ошибке, удаление образа, собранного по ошибке. Пользователю остаются миграции, правка compose-файла и настроек Claude Code, пуш и всё, что уходит с компьютера, вход в сервис, действия в браузере, рабочий сервер;

**Шаг 8, новый пункт — ssh:**

> - на сервер по ssh оркестратор заходит только по явному разрешению. Разрешение — слова пользователя, которые прямо называют заход: «да» на вопрос оркестратора о заходе или «зайди по ssh и сделай …». Вопрос о заходе называет сервер, команды и что они изменят. Ругань с повелительным словом, «сделай сам», «выполни» без слова о сервере — не разрешение: на них — вопрос о заходе одной строкой. Разрешение — на один заход и команды из вопроса; команды — по одной, вывод каждой — в чат;

**Шаг 8, ответ на вопрос.** Сейчас: «Вопрос пользователя в чате — ответ первым же сообщением, из уже известного: …». Дописать после этой фразы:

> Ответ — о спрошенном, одной-двумя фразами: шаги, команды, положение задачи и разбор причин, о которых вопрос не спрашивал, к ответу не прикладываются. Поручение — сразу делом, без ответа о намерении: на «пиши по шагам» — первый шаг.

**Шаг 8, «что происходит».** Сейчас: «цикл ждёт решения пользователя — вопрос ещё раз целиком, с вариантами». После: «…; цикл ждёт шага пользователя — этот шаг ещё раз, без остальных».

**Шаг 8, извинения.** Сейчас: «извинения, оценки себя и обещания исправиться в ответ не идут». После: «извинения, оценки себя и обещания исправиться в ответ не идут, и сам запрет — тоже: на вопрос о себе — одна фраза о деле, которое вопрос задел».
