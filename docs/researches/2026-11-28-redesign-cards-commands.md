# Карточки документов под три команды — правка на разрешение

Файл `template/.claude/skills/box-init/documents.md`: после шага «Три команды» проект подключает `box-connect`, а `box-update` только обновляет. Две строки карточек называют подключение командой `box-update`.

1. Строка 20, дерево документов, строка `PROTOCOL.md`.
   Сейчас: `…, порядок на месте: файл agent-box, кладёт box-update`
   После: `…, порядок на месте: файл agent-box, кладут box-connect и box-update`

2. Строка 128, карточка `PROTOCOL.md`, пункт «Пишется».
   Сейчас: `- Пишется: командой `box-update` — при подключении проекта и при каждом обновлении agent-box.`
   После: `- Пишется: командой `box-connect` — при подключении проекта, командой `box-update` — при каждом обновлении agent-box.`

Строки 40 и 127 — манифест и остановка обновления при правке протокола — верны и при трёх командах, их правка не нужна.
