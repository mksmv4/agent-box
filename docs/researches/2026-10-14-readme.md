1. В клоне agent-box — `git pull`, затем `docker compose build claude`.

   - рабочая копия git без `claude-box.yml` — команда первого запуска рабочей копии, в сессии `/box-init`.
5. Сборка документации проекта закончена — повторный `/box-init` заведёт новую (п. 5 выше).

Предложение — новый раздел «README» в `docs/RULES.md`, после «Конвенций кода». Правила — для `README.md` обвязки; README проектов задаёт карточка `skills/box-init/documents.md`, она вне задачи.

1. Раздел — одно дело читателя. Заголовок — дело глаголом в начальной форме: «Завести проект». Раздел не для всех — с «Необязательно:» в начале заголовка. Основание — Diátaxis, How-to guides § Pay attention to naming; Google, Headings and titles § Heading and title text.

Где — одно из трёх мест: терминал хоста в клоне agent-box, терминал хоста в папке проекта, сессия Claude в контейнере. Заполнитель вида `<задача>` поясняется под командой. ### Обвязка на машине

1. В терминале хоста, в папке клона agent-box, забери свежую версию и пересобери образ:

   ```bash
   git pull
   docker compose build claude
   ```

   Движок обновился уже после `git pull`: команда `agent-loop.sh` ведёт на скрипт клона. Свежие скиллы для проектов лежат в новом образе.

2. Ставил разрешение для Claude на компьютере (раздел [Необязательно: телефон для оркестратора](#необязательно-телефон-для-оркестратора))? Повтори команду в терминале хоста:

   ```bash
   agent-loop.sh --sandbox-rule
   ```

   Команда заменит прежнюю запись свежим текстом и покажет, как её видит Claude Code.

3. Закрой сессии Claude, открытые в контейнерах проектов. Контейнер берёт скиллы из образа только при старте. В старом контейнере `/box-update` возьмёт старые скиллы или скажет, что обновлять нечего.

### Каждый проект

Обновляй каждую копию проекта отдельно. У клона на другой машине и у рабочей копии git — свой файл `claude-box.yml` с сервисом Claude. Незакоммиченные правки закоммить заранее. С ними `/box-update` и `/box-init` перечислят правки и закончат без изменений.

В сессии набери `/box-init`. Старый сервис Claude здесь не годится: контейнер не стартует или `/box-init` в нём остановится с той же командой.

- **`claude-box.yml` нет** — проект заведён по старой схеме, сервис `claude` живёт в основном compose-файле. Запусти Claude старым сервисом:

  ```bash
  docker compose run --rm claude
  ```

  В сессии набери `/box-init`. Он перенесёт сервис в `claude-box.yml` и назовёт строки старого сервиса в основном compose-файле. Убери эти строки руками. Дальше Claude запускается командой из первого пункта.

Если сборка документации в проекте уже закончена, `/box-init` заведёт новую — задачу `docs-<дата>` с вехой в роадмапе. Вести её или нет — решаешь ты.
