Образец проекта — `/etc/claude-box/template/`. Текущий каталог — корень проекта.

1. **Проверки.** Нет `docs/PROTOCOL.md` или `docs/tasks/` — назвать это и закончить без правок: проект заводится в обвязку `/box-init`. Коммит в конце забирает всё рабочее дерево, поэтому на старте оно чистое: `git status --porcelain` непуст — перечислить правки и закончить без правок.

2. **Сверка.** `diff -r` образца с проектной копией — у `docs/PROTOCOL.md` и `.claude/skills/box-next/`. Совпали обе — назвать это и закончить без правок: обвязка проекта свежая, либо контейнер открыт до пересборки образа и несёт старый образец.

3. **Копии.** Разошедшееся — свежей копией из образца поверх.

4. **Завершение** — как у работы вне задачи: `docs/PROTOCOL.md` § Протокол сессии, «Завершение», шаги 1, 2, 4–6.

5. **Итог пользователю:** что изменилось в работе сессий — словами поведения, по разнице из шага 2; копии под `.gitignore` проекта (`git check-ignore`) — назвать: в git они не попадут. Дальше — `/box-next <задача>` в новой сессии: протокол приходит автозагрузкой хаба на старте сессии, эта сессия работает по старому.
