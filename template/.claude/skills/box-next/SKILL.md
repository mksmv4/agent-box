argument-hint: "[задача]"

1. Задача сессии — `$ARGUMENTS`. Аргумент пуст — вопрос пользователю инструментом `AskUserQuestion`: варианты — до трёх первых строк задач без чекбокса под первой вехой без чекбокса в `docs/ROADMAP.md` § Вехи, в описании варианта — статус из первой строки таск-файла; последний вариант — конец сессии без шага. Таких строк нет — назвать веху и закончить сессию без правок.
2. Открыть таск-файл `docs/tasks/<задача>.md`. Статус «блокер» и в секции «Блокер» строка, начинающаяся с «ответ:» в любом регистре, — блокер снят пользователем или оркестратором: первая строка — `статус: в работе`. Статус в первой строке не «в работе» — назвать его и закончить сессию без правок.
3. Сделать один шаг — первый незакрытый чекбокс очереди в «Постановке»; недоделанный шаг продолжить от точки, записанной в «Контексте». Критерии завершения шага и блокера — в «Постановке».
4. Завершить сессию по `docs/PROTOCOL.md`, § Протокол сессии, список «Завершение».
5. **Итог пользователю** — последним сообщением, и при конце сессии в шагах 1–2: что сделано, где остановился недоделанный шаг, статус задачи; дальше — действие пользователя по исходу:
   - статус «в работе» — `/box-next <задача>` в новой сессии: следующий шаг или продолжение начатого;
   - статус «блокер» — вопрос из секции «Блокер»; ответ — строкой «ответ:» в этой секции, затем `/box-next <задача>` в новой сессии;
   - статус «готово» — проверка сделанного по записям `docs/JOURNAL.md` и хвостам «Контекста» или ревью `/box-review <задача>`, затем QA `/box-qa <задача>`; принято — чекбокс строке задачи в `docs/ROADMAP.md`;
   - в первой незакрытой вехе нет задач без чекбокса — закрытие вехи командой «закрой веху <веха>» (`docs/PROTOCOL.md` § Протокол закрытия вехи) или новая задача `/box-task`.
